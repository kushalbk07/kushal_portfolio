# Kushal BK | Portfolio

Personal portfolio website showcasing my skills, what I'm currently learning, and the projects I've built.

Built with plain **HTML, CSS and JavaScript** (no frameworks or build step).

## Sections

- **Home**: introduction and links
- **About**: short bio and quick stats
- **Skills**: what I know, plus what I'm currently learning
- **Projects**: featured work
- **Contact**: message form and email

## Projects

- **PocketNepal** (`pocketnepal/`): expense tracker and bill splitter in Nepali Rupees. Plain HTML, CSS and JavaScript, with Chart.js for the charts. Data stays in the browser (LocalStorage).
- **Nepal Weather & Flood Risk Monitor** (`nepal-flood-monitor.html`): live weather and river flood-risk dashboard.
- **Momo Hub** and **Sathi Collection**: e-commerce storefronts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Add a new project

1. Open `index.html` and find the `TEMPLATE` comment inside the `#projects` section.
2. Copy that block, paste it above the "More coming soon" card, and remove the comment markers.
3. Fill in the title, description, tech tags, and your live demo / GitHub links.

## Deploy with GitHub Pages

1. Push the code to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Your site will be live at `https://kushalbk07.github.io/kushal_portfolio/`.
